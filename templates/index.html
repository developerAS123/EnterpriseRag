Project Overview & Architecture

Production-style Enterprise IT Support Agentic RAG Copilot built for ₹0 Free-Tier Cloud Deployment.

Core Capabilities

  • Grounded RAG Pipeline: Searches private Pinecone vector store (384-dim) before falling back to external web search.
  • LangGraph Agentic Control: Conditional routing across 16 DAG nodes, evidence quality grading, and query rewriting.
  • Self-Correcting Verification: Dedicated verification node cross-checks generated answers against retrieved evidence to eliminate hallucination.
  • Human-in-the-Loop (HITL) Gate: High-severity tickets (P1/P2) require explicit administrator approval before execution.
  • Tool Registry: Controlled allowlisted tools with Pydantic validation (KB search, Web search, IT checklists, Tickets).
  • Session-Isolated Memory: Multi-turn conversation context preserved per session without cross-user leakage.

Free-Tier Deployment

Architecture strictly engineered for ₹0 deployment budget:

Compute: Render Free Web Service (512MB RAM)
Inference: Groq API (Free Tier LLM)
Vectors: Pinecone Starter (1 index, 2GB free)
Web Search: Tavily API (1,000 free req/mo)
Embeddings: Local all-MiniLM-L6-v2 (~90MB RAM)
